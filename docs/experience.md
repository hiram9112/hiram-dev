# Experience

## Under the Surface

Hiram Dev is an engineering casebook built around a continuous, scroll-linked cutaway. A conceptual interface separates into Surface, Application, Data, Integrations, Reliability and Production. The final view holds all six layers together: one interface depends on a whole system.

The cutaway illustrates the narrative; it is explicitly not a BeneHom screenshot or an exact architecture diagram. BeneHom supplies the inspectable evidence, rather than becoming the subject of a project tour.

## Visual system

- Lilac `#dcd5f0` carries the discovery scene and contact area.
- Ink `#292339` carries typography and the evidence section.
- Paper `#f6f5f8` provides a quiet profile surface.
- Aqua `#b6e4dc` distinguishes the data plane and evidence links.
- Violet `#6d55a5` belongs to the cutaway's intermediate layers.
- Locally hosted Sora provides display typography; Source Sans 3 provides reading text. Their licenses ship with the font files.

Large left-aligned narrative type sits beside the cutaway on desktop. On phones, text sits above the same scene. The evidence uses a reading-oriented list with optional native disclosures, not a grid of projects or proficiency badges.

## Interaction and access

Native scrolling opens the cutaway continuously and reverses it when scrolling back. Chapter links offer direct access; a persistent in-scene link and keyboard skip link lead straight to the evidence. There is no scroll interception, automatic playback or forced snapping.

Reduced motion and short viewports use a static, sequential reading layout. Without JavaScript, the narrative and evidence remain readable. The evidence section is always available independently of animation.

GitHub, the live product and repository paths provide inspection routes. The LinkedIn address is verified against Hiram's public GitHub profile README. Contact uses LinkedIn. `/cv` is a printable, work-focused technical profile using only documented evidence; it does not invent employment history, education or qualifications.
